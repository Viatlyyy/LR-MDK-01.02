# Каталог с карточками товаров

## Готовый запуск

Откройте `App/WindowsFormsApp1.exe` в Windows. Папку `App` переносите целиком: в ней находятся необходимые DLL и изображения. Приложение использует .NET Framework 4.7.2 или совместимую установленную версию .NET Framework 4.x.

## Visual Studio

Откройте `WindowsFormsApp1.sln`, восстановите пакеты NuGet и соберите решение. Запускаемый проект — `WindowsFormsApp1`. Для сборки нужен набор разработки .NET Framework 4.7.2.

Карточка находится в проекте `DemoUIComponents`: `ProductCard/ProductCard.cs` → «Просмотреть конструктор». Визуальная разметка хранится в `ProductCard.Designer.cs`, заглушка — в `ProductCard.resx`. Товары задаются в `DemoLib/Models/ProductsModel.cs`.

## Товары и оформление

Три позиции из материалов экзамена: кроссовки «Драйв», мужские демисезонные ботинки «Барбари» и босоножки «Песчаный берег». Вторая карточка красная (`#FF8080`), поскольку суммарный остаток — две пары; условие подсветки — не более трёх пар. Наведение использует `#70B2AF`, обычный фон — `#D2F6E7`.

Изображение расположено слева, производитель и название сверху, категория, количество и состав по центру, цена справа. Цена отображается в рублях с двумя десятичными знаками.
