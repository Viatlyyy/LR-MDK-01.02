# Демо-экзамен: репозиторий заказов

Откройте `WindowsFormsApp1.sln` в Visual Studio с компонентами Windows Forms и .NET Framework 4.7.2, восстановите NuGet-пакеты и соберите решение. Готовый запуск — `App/WindowsFormsApp1.exe`.

`DemoLib/Repositories/IOrdersRepository.cs` объявляет `IEnumerable<Order> Load()`. Модель получает источник через `UpdatePrices(IOrdersRepository ordersRepository)`, загружает заказы один раз и применяет существующее правило скидки 25% за отсутствие продаж в предыдущем календарном месяце. Список заказов в метод не передаётся.

Реальное подключение БД на этом этапе не реализовано. Конструктор `MainForm(IOrdersRepository ordersRepository)` позволяет подключить будущую реализацию; обычный конструктор сохранён для запуска и конструктора форм. Без репозитория отображаются исходные цены, перерасчёт не выполняется. Пустая последовательность от подключённого репозитория означает отсутствие заказов и даёт скидку всем товарам.

В `DemoTesting` находятся 8 тестов: 6 прежних проверок расчёта, мок-тест взаимодействия с репозиторием и проверка отсутствующей зависимости. Ручной мок `Mocks/OrdersRepositoryMock.cs` возвращает тестовые заказы и считает вызовы `Load()`. Основной мок-тест проверяет один вызов загрузки, сохранение цены проданного товара и скидку для непроданного. Запуск: **Тест → Запустить все тесты**.
