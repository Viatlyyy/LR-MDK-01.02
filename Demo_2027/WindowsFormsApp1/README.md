# Демо-экзамен: тесты UpdatePrices

Версия проекта Demo_2027 с исправлениями сборки, настройками конструктора WinForms и восемью модульными тестами метода `ProductsModel.UpdatePrices`.

## Открытие и запуск

1. Откройте `WindowsFormsApp1.sln` в Visual Studio.
2. Восстановите пакеты NuGet и соберите решение. Нужен набор разработки .NET Framework 4.7.2.
3. Для запуска приложения выберите проект `WindowsFormsApp1`.
4. Для запуска тестов откройте обозреватель тестов и выберите «Запустить все тесты».

В проектах интерфейса включён `UseWinFormsOutOfProcDesigner`. Для этого режима конструктора нужна Visual Studio 2022 версии 17.9 или новее.

## Сценарии тестирования

Тесты находятся в `DemoTesting/TOrder.cs`:

1. Пустой список заказов: цена 1000 уменьшается до 750.
2. Продажа в первый день прошлого месяца: цена остаётся 1000.
3. Продажа в конце последнего дня прошлого месяца: цена остаётся 1000.
4. Продажи вне прошлого месяца: цена уменьшается до 750.
5. Продан только второй товар: скидку получает только первый товар.
6. Заказ без позиций: цена уменьшается до 750.
7. Несколько товаров в одном заказе: цены обоих проданных товаров сохраняются.
8. Подходящая продажа только в третьем заказе: цена сохраняется.

Каждый тест использует новую модель. Даты вычисляются относительно текущего месяца. В `UpdatePrices` исправлена верхняя граница периода: учитывается весь прошлый календарный месяц, включая последний день.
